# 📚 Odin Library
> *Your digital bookshelf.*

This project is a small, interactive web application to track your personal reading list. It was built as part of the curriculum for [The Odin Project](https://www.theodinproject.com/lessons/node-path-javascript-library).

## ✨ Features

* **Add new books:** Enter a title, author, page count, and whether you have read it.
* **Track reading status:** Easily toggle the read status of a book with a single click.
* **Remove books:** Delete books from your library when you no longer want them tracked.
* **Dynamically Rendered:** The interface updates instantly using pure JavaScript DOM manipulation.

## 🛠️ Built With

* HTML5
* CSS3
* Vanilla JavaScript (ES6)
